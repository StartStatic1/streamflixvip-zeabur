Documentação da Partner API

API HTTP para parceiros integrarem catálogo, fontes de filmes/séries e canais ao vivo no próprio aplicativo ou backend. Autenticação por token Bearer.

1. Início rápido

O que você recebe de nós:

  • Base URL — https://www.streamflixvip.online
  • Token — formato sf_live_... (gerado no painel)

Token de exemplo (não funciona de verdade): sf_live_EXEMPLO_nao_use_em_producao_abc123XYZ

Teste em 10 segundos:

curl -s "https://www.streamflixvip.online/api/partner?action=ping" \
  -H "Authorization: Bearer SEU_TOKEN_AQUI"

Resposta esperada (HTTP 200):

{
  "ok": true,
  "partner": "NomeDoParceiro",
  "scopes": ["sources", "catalog", "livetv"],
  "docs": { ... }
}

2. Autenticação

Todas as rotas exigem autenticação. Duas formas aceitas:

HeaderValor
AuthorizationBearer sf_live_...
X-API-Keysf_live_...

Recomendado: Authorization: Bearer.

3. Base URL

https://www.streamflixvip.online

Todas as rotas começam com /api/partner.

4. Endpoints

GET Ping / Me

/api/partner?action=ping

Valida o token e devolve nome do parceiro + escopos liberados. Ideal para health-check.

Resposta 200

{
  "ok": true,
  "partner": "CineMeck",
  "scopes": ["sources", "catalog", "livetv"],
  "docs": {
    "sources": "GET /api/partner?action=sources&tmdb_id=550&type=movie",
    "sources_tv": "GET /api/partner?action=sources&tmdb_id=1396&type=tv&season=1&episode=1",
    "catalog": "GET /api/partner?action=catalog&type=movie&limit=50",
    "livetv": "GET /api/partner?action=livetv"
  }
}

GET Sources (filme ou episódio)

/api/partner?action=sources&tmdb_id={id}&type=movie|tv

Retorna as fontes ativas de um título (ordenadas por prioridade).

ParâmetroObrigatórioDescrição
tmdb_idsimID do TMDB
typesimmovie ou tv
seasonsó TVnúmero da temporada
episodesó TVnúmero do episódio

Filme (ex. Fight Club = 550)

GET /api/partner?action=sources&tmdb_id=550&type=movie

Série (ex. Breaking Bad S01E01)

GET /api/partner?action=sources&tmdb_id=1396&type=tv&season=1&episode=1

Resposta 200

  "type": "movie",
  "season": null,
  "episode": null,

GET Catalog

/api/partner?action=catalog&type=movie|tv|all&limit=50&offset=0

Lista títulos que possuem fonte ativa (para montar catálogo no app do parceiro).

ParâmetroDefaultDescrição
typeallmovie, tv ou all
limit50máx. 100
offset0paginação

Resposta 200

{
  "items": [
    {
      "tmdb_id": 8555,
      "media_type": "movie",
      "title": "Plataforma do Medo",
      "poster_path": "/abc123.jpg"
    }
  ],
  "limit": 50,
  "offset": 0
}

poster_path é o path do TMDB (prefixe com https://image.tmdb.org/t/p/w342).

Escopo: catalog ou sources.

5. Exemplos prontos

cURL

# Ping
curl -s "https://www.streamflixvip.online/api/partner?action=ping" \
  -H "Authorization: Bearer sf_live_SEU_TOKEN"

# Fontes de um filme
curl -s "https://www.streamflixvip.online/api/partner?action=sources&tmdb_id=550&type=movie" \
  -H "Authorization: Bearer sf_live_SEU_TOKEN"

# Catálogo
curl -s "https://www.streamflixvip.online/api/partner?action=catalog&type=movie&limit=20" \
  -H "Authorization: Bearer sf_live_SEU_TOKEN"

JavaScript (fetch)

const BASE = 'https://www.streamflixvip.online';
const TOKEN = 'sf_live_SEU_TOKEN'; // só no backend / env

async function partnerGet(action, params = {}) {
  const qs = new URLSearchParams({ action, ...params });
  const res = await fetch(`${BASE}/api/partner?${qs}`, {
    headers: { Authorization: `Bearer ${TOKEN}` },
  });
  if (!res.ok) throw new Error(await res.text());
  return res.json();
}

// uso
const me = await partnerGet('ping');
const sources = await partnerGet('sources', { tmdb_id: 550, type: 'movie' });
const catalog = await partnerGet('catalog', { type: 'movie', limit: 30 });

Como encaixar no app do parceiro

  1. Guarde o token somente no servidor dele (env / secrets). Nunca no APK.
  2. Quando o usuário clicar em “Assistir”, o backend dele chama action=sources com o tmdb_id.
  3. Devolve as URLs para o player (ExoPlayer, VLC, etc.).
  4. Opcional: sincronizar catalog periodicamente para a base dele (não usa nosso Supabase).

7. Rate limit & escopos

Rate limit — definido por parceiro no painel (ex.: 60 req/min). Acima disso → HTTP 429.

Escopos possíveis

  • sources — links de filme/série
  • catalog — listagem de títulos
  • livetv — canais ao vivo

O painel admin controla quais escopos cada token tem e pode pausar/revogar a qualquer momento.

8. Segurança (obrigatório)

  • Nunca embuta o token no APK, no frontend ou em repositório público.
  • Use sempre no backend do parceiro (Node, PHP, Python, etc.).
  • Se o token vazar, o dono da API pausa ou gera nova chave no painel em segundos — a antiga para de funcionar.
  • Não há acesso ao nosso Supabase: só respostas HTTP filtradas pelos escopos do token.
  • CORS liberado para facilitar testes; produção deve ir pelo servidor do parceiro.
