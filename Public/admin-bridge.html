Painel bloqueou o IP do servidor

O painel não aceita o servidor, mas aceita o celular. Faça pelo celular:

  1. Toque em Abrir lista de pastas
  2. Na página que abrir: toque na tela e segure → Selecionar tudo → Copiar
  3. Volte aqui, cole no campo abaixo e toque Usar JSON colado
  4. Se as pastas vierem vazias, faça o mesmo com Abrir lista de canais

Avançado (opcional): atalho nos favoritos

Abra o painel, salve o atalho como favorito e execute-o com a página do painel aberta.
