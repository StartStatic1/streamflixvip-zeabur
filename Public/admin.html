📡 Nova fonte IPTV

Cadastre uma playlist Xtream. O sistema sincroniza automaticamente todo dia, casando os filmes com o TMDB e adicionando como um servidor separado (nome = o que você colocar abaixo) na tela de cada filme.

📋 Fontes cadastradas

O progresso avança sozinho (cron diário). "Pausar" impede novas sincronizações sem apagar os filmes já cadastrados. "Excluir" remove a fonte E todos os filmes que vieram dela — use quando a assinatura vencer de vez.

🔗 Novo parceiro de embed

Gera uma key única pra distribuir o player (/embed) num site de terceiro via iframe. Domínio é opcional — se preenchido, o player só toca naquele site; se vazio, funciona em qualquer lugar (útil pra testar, mas recomendado travar depois). Desativar aqui derruba o player na hora, em qualquer site que esteja usando essa key.

📋 Parceiros cadastrados

A key completa aparece só na criação (copie e guarde). Depois disso, o painel mostra só os primeiros caracteres pra você identificar qual é qual.
