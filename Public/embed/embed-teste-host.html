🔒 Teste da trava de Host — StreamFlixVIP Embed

Esta página existe pra responder uma pergunta específica: "se eu configurar um Host no parceiro, o player realmente só toca dentro daquele site?". O teste comum (colar o link do embed direto no navegador, ou num iframe dentro do próprio painel) não prova isso — nesses casos o navegador manda o próprio domínio do painel como origem, o que não representa um site de terceiro de verdade.

1. Dados do parceiro

Cole a key gerada no admin (aba 🔗 Embeds) e o TMDB ID de um título já cadastrado.

2. Teste A — carregamento normal como o admin vendo

Carrega o iframe normalmente nesta página. Se o parceiro tiver Host configurado, isso só vai funcionar se esta própria página estiver hospedada no domínio configurado — senão deve bloquear.

3. Teste B — sem informação de origem simula o bug antigo

Carrega o mesmo iframe dentro de um <iframe sandbox> sem allow-same-origin, o que força o navegador a não mandar nem Referer nem Origin — exatamente a situação que antes vazava (liberava o player mesmo com Host configurado). Depois da correção, isso deve sempre mostrar "Conteúdo indisponível" quando o parceiro tiver Host configurado.
